## Project Description

R.I.P. (Research • Internship • Project) is a web-based platform designed to help university students manage their research, internship and thesis-related activities in one place.

The system provides tools for finding supervisors, exploring research labs, discovering research papers, browsing internship opportunities and joining thesis study circles.

## Features

- Smart Supervisor Finder
- Research Interest Matching
- Faculty Profile Explorer
- Availability Tracker
- Research Lab Board

- Internship Opportunity Portal
- Project Teammate Finder
- Research Paper Discovery
- Discussion Forum
- Thesis Group Finder

- Research Event & Conference Hub 
- Admin Control Panel
- Real time Notification Center 
- Personalized Dashboard 
- Academic FAQ Chatbot

- Thesis Progress Tracker & Hugging Face AI Assistant
- Overleaf-Style Thesis Document Manager 
- Resource Library
- Peer Thesis Archive 
- Citation & Reference Manager 

## Technologies

Backend: Python (http.server, sqlite3)
